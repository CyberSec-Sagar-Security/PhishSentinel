# Data Directory

This directory contains training and test data for PhishLens.

## Structure

```
data/
├── raw/        ← Place downloaded corpus files here (NOT committed to Git)
├── processed/  ← Auto-generated by pipeline (NOT committed to Git)
└── README.md   ← This file
```

## Required Datasets

### 1. MeAJOR Phishing Email Corpus (Primary Training Data)

- **Source:** https://github.com/rf-peixoto/phishing_pot
- **Size:** 135,894 emails
- **Format:** CSV with `label` and `email` columns
- **Download:**
  ```bash
  git clone https://github.com/rf-peixoto/phishing_pot
  cp phishing_pot/dataset/dataset.csv data/raw/meajor.csv
  ```

### 2. SpamAssassin Public Corpus (Stress Testing / OOD Evaluation)

- **Source:** https://spamassassin.apache.org/old/publiccorpus/
- **Size:** ~6,000 emails (gold-standard labelled)
- **Download:**
  ```bash
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_easy_ham.tar.bz2
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_spam.tar.bz2
  tar -xjf 20030228_easy_ham.tar.bz2 -C data/raw/spamassassin_ham/
  tar -xjf 20030228_spam.tar.bz2 -C data/raw/spamassassin_spam/
  ```

### 3. CASIS Phishing Dataset (Supplement — BEC Samples)

- **Source:** https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset
- **Size:** 82,000+ emails
- **Download:** Requires Kaggle account. Use `kaggle datasets download naserabdullahalam/phishing-email-dataset`
- Place as: `data/raw/casis.csv`

### 4. PhishTank URL Dataset (URL Feature Ground Truth)

- **Source:** https://www.phishtank.com/developer_info.php
- **Format:** CSV/JSON, updated daily
- **Download:** Register free account, download `verified_online.csv`
- Place as: `data/raw/phishtank_urls.csv`

### 5. Nazario Phishing Corpus (Temporal Robustness Testing)

- **Source:** https://monkey.org/~jose/phishing/
- **Size:** 8,000+ emails (2004–2007)
- **Use:** Tests temporal feature drift — train on recent, test on historic

## Kaggle Dataset Setup

Three of the PhishLens datasets are hosted on Kaggle and are downloaded
automatically by `python download_datasets.py` once your Kaggle credentials
are in place. Follow these steps once:

### Step 1 — Create a Kaggle account

Go to [https://www.kaggle.com](https://www.kaggle.com) and sign up (free).

### Step 2 — Generate an API token

1. Log in → click your profile picture (top-right) → **Settings**
2. Scroll to the **API** section → click **Create New API Token**
3. This downloads a file named `kaggle.json`

### Step 3 — Place the token file

| OS | Target path |
|----|-------------|
| Windows | `C:\Users\<your-username>\.kaggle\kaggle.json` |
| Linux / macOS | `~/.kaggle/kaggle.json` |

Create the `.kaggle` folder if it does not exist.

### Step 4 — Install the Kaggle CLI

```bash
pip install kaggle
kaggle --version      # should print e.g. "Kaggle API 1.6.14"
```

### Step 5 — Dataset identifiers

| Dataset | Kaggle slug | Used for |
|---------|-------------|----------|
| CASIS Phishing Email Dataset | `naserabdullahalam/phishing-email-dataset` | Phishing emails |
| Enron Email Dataset | `wcukierski/enron-email-dataset` | Legitimate (ham) emails |
| Nigerian Fraud Corpus | `rtatman/fraudulent-email-corpus` | Advance-fee fraud emails |

### Step 6 — Download automatically

```bash
python download_datasets.py
```

PhishLens will call the Kaggle CLI for all three datasets in one run.
If the CLI is not installed, the script prints a helpful message and skips
those datasets gracefully without crashing.


### 6. Cisco Umbrella 1M (Legitimate Domain Whitelist)

- **Source:** http://s3-us-west-1.amazonaws.com/umbrella-static/top-1m.csv.zip
- **Use:** Reduces false positives in brand impersonation detection
- Place as: `data/raw/umbrella_top1m.csv`

## Privacy & Legal Notice

**Do NOT commit raw email data to this repository.**
Email corpora contain real personal data. The `.gitignore` excludes all
`data/raw/` and `data/processed/` files automatically.

Only this `README.md` is tracked by Git.
